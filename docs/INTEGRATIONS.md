## How a template reaches an external system

1. The template's http/action nodes reference a credential by `credentialProvider` (e.g. `quickbooks`) — the runner picks the matching credential among the agent's attached `credentialIds`, strictly within the org.
2. URLs, headers and bodies are rendered with `{{secret.field}}`, `{{input.x}}`, `{{nodes.<id>.body.x}}` placeholders (no eval).
3. Every string equal to a decrypted secret value is replaced with `[redacted]` in logs, persisted outputs and approval payloads.
4. An `action` node may declare `compensate` (`{ kind: "http" | "log", ... }`). If the run later fails after retries, completed actions are compensated in reverse order and the run ends `rolled_back`.

## Process-mining import without a license

Export processes from the vendor UI to JSON and call the matching mapper (`mapPowerAutomateProcesses`, `mapUiPathTasks`, `mapMimicaProcesses`). Each returns rows ready for `workflows` insert with `basis: "observed"` and an evidence note naming the source — the analysis engine's own opportunity scoring then applies unchanged.
